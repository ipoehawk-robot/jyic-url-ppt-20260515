08 / 條件判斷

if / elif / else

條件判斷讓程式依照不同狀況走不同路徑。Python 使用縮排決定哪幾行屬於條件內部。

比較與邏輯：<、<=、>、>=、==、!=、and、or、not。
price = int(input())
if price < 100:
    print("cheap")
elif price < 200:
    print("okay")
else:
    print("expensive")

09 / 迴圈

while / for / range

迴圈讓電腦重複做事。while 像不斷執行的 if；for 逐一處理序列元素，常搭配 range()。

控制出口：break 結束迴圈；continue 跳過本輪。注意無窮迴圈。
for i in range(3):
    print(i)

i = 0
while i < 3:
    print(i)
    i += 1

11 / 資料檔案

CSV 與 File I/O

CSV 用逗號分隔資料；可用 split(',') 拆欄位。檔案讀寫包含 read、readline、write、append，建議用 with 自動關閉檔案。

核心心法：把文字檔拆成行，再把每行拆成欄位。
with open('file.csv') as f:
    data = f.read()
lines = data.split('\n')
rows = [line.split(',') for line in lines]

12 / 函數

模組化與重複使用

函數包含名稱、本體、輸入參數與回傳值。用 def 宣告，用 return 回傳結果。

好函數應說明：作用、輸入、輸出；避免直接修改外部資料造成混淆。
def get_1_to_n(n=5):
    alist = list(range(1, n+1))
    return alist

x = get_1_to_n(10)

13 / 作用域與物件

Scope、Mutable、Immutable

區域變數只活在函數內；全域變數存在主程式。List / dict / set 是可變物件；int / float / str / tuple 是不可變物件。

傳參數時要特別注意：修改可變物件內容，可能影響原始資料。
def listchange(l):
    l[0] = 'A'

alist = [1,2,3]
listchange(alist)
# alist 也會被改變

14 / 進階結構

Tuple、Dict、Set、Recursion

Tuple 有序不可變；Dict 用 key 找 value；Set 儲存唯一元素並支援集合運算；遞迴是函數呼叫自己，需要 Base Case。

這些是寫出更乾淨、更能處理複雜資料的基礎。
mytuple = (11,22,33)
mydict = {1:'one'}
aset = {11,22,33}

def fact(n):
    if n == 1: return 1
    return n * fact(n-1)

16 / OOP 與總結

物件導向：封裝、繼承、多型

Class 把資料與行為包成物件；封裝隱藏內部狀態，繼承重用父類別能力，多型讓同名方法在不同類別有不同實作。

講義結語：常用 Python 語法已具備，接下來靠題目與專案持續練習。
class Animal:
    def walk(self): print('walking')

class Dog(Animal):
    def walk(self): print('dog walking')
